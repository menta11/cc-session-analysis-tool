# 甘特图时间轴窗口 · 设计文档

> 日期：2026-08-05 · 状态：已批准 · 目标：甘特图顶部时间滑块 + ctrl滚轮缩放 + 水平滚动条，联动大纲树统计与 AI 分析

## 背景

当前甘特图固定显示全会话时间轴（`[startedAt, endedAt]`），无缩放、无范围选择。用户希望：
1. 顶部双滑块选择时间范围
2. ctrl+滚轮以焦点为中心缩放时间刻度
3. 缩放后底部出现/消失水平滚动条
4. 大纲树统计（总时间/占比/工具时长）随窗口变化
5. AI 分析可选「整会话」或「仅分析所选时间块」

## 核心概念：视图窗口

**视图窗口** = `[viewStart, viewEnd]`（绝对时间戳，ms），由**范围滑块**与**缩放**共同决定（叠加）。

- 默认窗口 = 全会话 `[startedAt, endedAt]`
- 滑块：直接设窗口边界；平滑拖动，**松手吸附到最近段边界**（不切段）
- ctrl+滚轮：以鼠标焦点时间点为中心，收缩/扩张窗口（放大=窗口变窄+刻度变密），**固定 1.2 倍/格**，有最小宽度（1s）与最大（全会话）边界
- 最终只有一个窗口状态，所有渲染/统计基于它

## 裁剪单位：视图用段，AI 用完整 turn

**两个裁剪单位分开用**（这是关键设计决策）：

| 消费者 | 裁剪单位 | 说明 |
|---|---|---|
| **视图层**（甘特图/大纲树统计） | **段** | `clipTreeToWindow` 裁剪 segments 到窗口，节点 ms = 裁剪后各段并集时长，wallMs = 窗口时长 |
| **AI 分析**（按窗口模式） | **完整 turn** | `clipSessionToWindow` 取窗口内完整 turns，跨边界 turn 整体保留，调用天然完整 |

**为什么不会出现「跨窗口被切开的调用」**：AI 分析给的是完整 turn → turn 内的 toolCalls 全部保留 → 详情面板调用列表**天然完整**。视图层的段裁剪只影响甘特显示与统计数字，**toolBucket.calls 详情列表不裁剪（保留完整）**。

## 架构

```
Session
   ├─ buildTreeNode ──→ 显示树（segments 绝对 ts）
   │      └─ clipTreeToWindow(tree, viewStart, viewEnd) ──→ 裁剪树（窗口内段 + 重算 ms/wallMs）→ 大纲树+甘特渲染
   └─ clipSessionToWindow(session, viewStart, viewEnd) ──→ 窗口化 Session（窗口内完整 turns）→ AI「按窗口分析」
```

**核心原则**：裁剪与窗口计算全部是 **core 层纯函数**（可单测，零框架依赖），组件只持有状态 + 渲染。

## 1. core/view/window.ts（新增）— 窗口纯函数

```ts
export interface ViewWindow { start: number; end: number }

/** 窗口时长（>0 才有意义） */
export function windowDuration(w: ViewWindow): number

/** clamp 窗口到会话范围 [lo, hi]，保证 start < end 且最小宽度 */
export function clampWindow(w: ViewWindow, lo: number, hi: number, minMs: number): ViewWindow

/** ctrl+滚轮缩放：以焦点时间点 pivot 为中心，factor>1 放大（窗口变窄），<1 缩小 */
export function zoomWindow(w: ViewWindow, pivot: number, factor: number, lo: number, hi: number, minMs: number): ViewWindow

/** 滑块吸附：把窗口边界吸附到最近的段边界（不切段） */
export function snapToSegmentBoundary(ts: number, boundaries: number[]): number

/** 像素比：窗口宽度 / 像素宽（px per ms），用于甘特缩放后的定位 */
export function pxPerMs(w: ViewWindow, pxWidth: number): number
```

- `boundaries` = 所有分类段边界的并集（排序去重），供滑块吸附
- 全部纯函数，单测覆盖

## 2. core/view/treeView.ts（扩展）— 视图层段裁剪

新增导出：

```ts
/** 把树裁剪到窗口：节点 segments 裁剪到 [viewStart, viewEnd]（段边界吸附由调用方保证），
 *  ms = 裁剪后各段并集时长，wallMs = 窗口时长（统一传给所有节点）。返回新树，其它字段不变。 */
export function clipTreeToWindow(tree: TreeNode, viewStart: number, viewEnd: number): TreeNode
```

- 递归复制树，`segments` 用 `clipInterval(iv, viewStart, viewEnd)` 裁剪（`core/model/timeline.ts` 加 helper）
- 节点 `ms` = `unionDuration(clippedSegments)`
- 节点 `wallMs` = `viewEnd - viewStart`（占比/横条基准）
- **`calls`（toolBucket 详情）保留完整**（不裁剪）——详情面板显示完整调用，甘特只显示窗口内
- 根节点 `ms` = 窗口时长，`label` 不变

## 3. core/model/timeline.ts（扩展）— 区间裁剪

```ts
/** 区间裁剪到 [lo, hi]，无交集返回 null */
export function clipInterval(iv: Interval, lo: number, hi: number): Interval | null
```

## 4. core/ai/（扩展）— 窗口化 AI 分析（完整 turn）

新增 `clipSessionToWindow(session, viewStart, viewEnd): Session`：

- 取**窗口内完整 turns**（turn 的 userMsg.ts 或任意 assistantMsgs/toolCalls 落在窗口内 → 保留整个 turn）
- **跨边界 turn 整体保留**（不裁剪 turn 内部）
- 返回新 Session（`startedAt/endedAt` 设为窗口边界，`turns` 为窗口内子集）
- 供 `buildAnalyzeRequest` 的「按窗口分析」模式使用

`analyzeRequest.ts` 加 `opts.window?: ViewWindow`：

```ts
buildAnalyzeRequest(session, { kind: 'whole', ..., window })  // window 存在 → clipSessionToWindow 后 buildDigest
```

整会话模式（默认）不传 window → 行为不变。

## 5. src/App.tsx（扩展）— 窗口状态 + AI 模式

- 新增窗口状态：`viewWindow: ViewWindow`（默认全会话）
- 新增 AI 范围模式：`aiScope: 'whole' | 'window'`（勾选「仅分析所选时间块」）
- `analyze()` 传 `window: aiScope === 'window' ? viewWindow : undefined`
- **窗口变化时报告处理**：保留旧报告，**右下角常驻提示**「窗口已变化，建议重新生成」；若窗口改回原状（等于生成报告时的窗口）则提示消失
- 记录生成报告时的窗口（`reportWindow`），变化时比较

## 6. src/components/TimeTree.tsx（扩展）— 滑块/缩放/滚动条

- 顶部加**双滑块轨道**（RangeSlider）：滑动设 `viewWindow`，松手 `snapToSegmentBoundary`
- **ctrl+滚轮**（onWheel 监听，`e.ctrlKey`）→ `zoomWindow(当前窗口, 鼠标焦点时间, 1.2)`，有边界限制
- **水平滚动条**：甘特内容宽度 = `ganttW * (rootWall / windowDuration)`，> 可视宽时出现滚动条；缩放后自动重算
- 表头时间刻度：当前 `ticks=[0,.25,.5,.75,1]` 改为**按窗口动态刻度**（窗口内均分，缩放越深刻度越密）
- 甘特渲染：`Gantt` 组件加 `viewStart/viewEnd`，段定位改 `(s.start - viewStart) / windowDuration`，窗口外段裁剪/隐藏
- 大纲树统计：`Row` 的 `ms`/`pct` 用裁剪树的 `ms`/`wallMs`

## 关键约束

- **core 层零框架依赖**，新逻辑全在 core/ 纯函数 + 单测
- **容错**：窗口非法（start>=end、超范围）→ `clampWindow` 兜底
- **滑块吸附段边界**保统计精确（不切段）
- AI 整会话模式默认，窗口模式可选（勾选）
- 甘特渲染与统计共用同一窗口状态，保证数字与甘特一致
- 视图段裁剪与 AI 完整 turn 裁剪**分开**：视图统计精确到段，AI 分析完整可信
